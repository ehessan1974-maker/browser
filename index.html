مرحبًا! أنا وكيل برق. اطلب مني فتح موقع، أو البحث عن شيء، أو تلخيص صفحة — وسأنفّذها بسرعة 85ms وبلا تتبّع.

محاكاة تفاعلية تعمل محليًا في صفحتك — بنفس منطق الحجب المستخدم في تطبيق برق الفعلي.

لماذا برق؟

مبني للسرعة. مصمّم للخصوصية.

كل قرار هندسي في برق يخدم ثلاثة أهداف: أن يبدأ فورًا، أن يحمّل الصفحات بسرعة تفوق أي متصفح تقليدي، وأن يبقى بياناتك على جهازك وحده.

تشغيل شبه فوري

نواة خفيفة لا تحمّل مكوّنات غير ضرورية؛ يفتح برق في أقل من ثانية حتى على الأجهزة القديمة.

تحميل في 85 مللي ثانية

محرك عرض مبسّط وجلب ذكي للبيانات يقدّمان الصفحة قبل أن تكتمل رفّة العين.

30MB من الذاكرة فقط

إدارة ذاكرة صارمة تُغلق العمليات الخاملة فورًا، فلا يستنزف المتصفح موارد جهازك.

أكثر من 3,500 متعقّب محجوب

قائمة حظر محدّثة باستمرار تعمل محليًا على جهازك وتحجب التتبّع قبل تحميله.

إعلانات وتحليلات تحت الصفر

حجب شامل للإعلانات وأكواد التحليلات وبكسلات التتبّع قبل أن تُحمَّل أصلًا.

صديق الأتمتة والوكلاء

واجهة CLI وHTTP API ومقابس أحداث جاهزة لوكلاء الذكاء الاصطناعي وتدفقات العمل الآلي.

للوكلاء والمطوّرين

اللغة المفضّلة لوكلائك

صُمّم برق ليكون يدي وقدمي وكلاء الذكاء الاصطناعي: واجهة سطر أوامر كاملة، وHTTP API منظّم، ومقابس أحداث لحظية — كلها تعمل بنفس نواة الخصوصية.

barq — shell

$ barq open https://example.com --stealth

✓ page ready in 78ms · 12 trackers blocked · 29MB ram

$ barq agent summarize --url https://news.example.com

✓ clean DOM 142KB delivered · 0 ads · 0 trackers

$ barq api serve --port 9090 --token $AGENT_TOKEN

✓ http api ready on :9090 — awaiting agent commands

$ barq block sync

✓ 3,512 tracker rules updated — locally, no cloud

واجهة CLI كاملة

أوامر ذرّية لكل شيء: فتح، بحث، تلخيص، حجب — قابلة للتسلسل في أي سكربت.

HTTP API + Webhooks

نتائج JSON منظّمة لكل عملية؛ تتكامل مع n8n وZapier وأي وكيل مباشرة.

أحداث لحظية

مقابس WebSocket تبثّ أحداث التصفح لحظة بلحظة إلى وكلائك.

الخصوصية أولًا

خصوصيتك ليست ميزة إضافية — إنها الأساس

بينما يحوّل المتصفحات الأخرى تصفحك إلى منتج يُباع، يعمل برق بمنطق معاكس: كل ما يحدث في جهازك يبقى في جهازك.

  • حظر محلي 100%

    قوائم الحظر تعمل على جهازك؛ لا يُرسل أي طلب لفحص الروابط أو التحقق.

  • بلا سجل

    لا يحفظ برق ما تتصفحه ولا يربط جلساتك ببعضها، ويمكنك مسح كل شيء بضغطة.

  • مقاومة بصمة الجهاز

    تعطيل تقنيات fingerprinting التي تعرّف بك حتى دون كوكيز.

  • بلا اتصالات خفية

    البرنامج يعمل محلياً بالكامل ولا يتصل بأي خدمة تجسس أو تتبع — يمكنك مراقبة سلوكه بنفسك في أي وقت.
