# برق — Barq ⚡

> متصفح خفيف مصمّم للأتمتة ووكلاء الذكاء الاصطناعي — تصفّح أسرع، أخفّ، وأكثر خصوصية.

![Next.js](https://img.shields.io/badge/Next.js-16-black) ![TypeScript](https://img.shields.io/badge/TypeScript-5-blue) ![Tailwind](https://img.shields.io/badge/Tailwind-4-teal) ![License](https://img.shields.io/badge/license-TBD-green)

## 💡 الفكرة

**برق** هو موقع تعريفي تفاعلي (Landing Page) لمفهوم متصفح يضع ثلاثة أهداف فوق أي اعتبار:

| الهدف | الرقم المستهدف |
| --- | --- |
| تشغيل شبه فوري | < 0.8 ثانية |
| متوسط تحميل الصفحة | ~85 مللي ثانية |
| استهلاك الذاكرة | ~30MB فقط |
| المتعقّبات المحجوبة تلقائيًا | 3,512+ قاعدة حظر |

مع تكامل كامل مع الأتمتة ووكلاء الذكاء الاصطناعي عبر CLI وHTTP API ومقابس أحداث لحظية.

## ✨ المميزات داخل الموقع

- 🖥️ **محاكاة متصفح تفاعلية**: اكتب أي عنوان أو كلمة بحث وشاهد الدرع يحجب المتعقّبات لحظة بلحظة (تبويبات، تنقّل، سجل، HUD للأداء)
- 🛡️ **درع الخصوصية**: تفصيل المتعقّبات حسب الفئة (إعلانات / تحليلات / بصمة / اجتماعي) مع عدّادات حيّة
- 🤖 **وكيل ذكاء اصطناعي مدمج**: محادثة حقيقية مع نموذج LLM ينفّذ مهام التصفح ويفتح المواقع
- 📊 عدّادات أداء متحركة + خط بيانات مباشر من `/api/stats`
- 🌐 عربية RTL بالكامل، تصميم داكن، متجاوب مع الجوال

## 🚀 التشغيل

```bash
# التبعيات
bun install

# قاعدة البيانات (اختياري للمشاهدة)
bun run db:push

# التطوير
bun run dev        # http://localhost:3000

# فحص الجودة
bun run lint
```

## 🔌 الواجهات البرمجية

| المسار | الطريقة | الوظيفة |
| --- | --- | --- |
| `/api/browse` | `POST {url}` | يحاكي جلب صفحة مع قائمة المتعقّبات المحجوبة والأداء |
| `/api/stats` | `GET` | إحصاءات الشبكة التراكمية (صفحات، حجب، متوسطات) |
| `/api/agent` | `POST {messages}` | وكيل ذكي يستجيب بمهام تصفح قابلة للتنفيذ |

## 🗂️ البنية

